# Final master-specification audit

Status: COMPLETE for release 0.12.0. Both full suites, packaging, security, docs and scoped cleanup passed.
Client date: 2026-10-02. This audit compares the user's complete 12-phase master
specification with the actual repository, always named Parallax Risk. Historical
phase reports preserve their original results. There is no Phase 13 implementation.

## How to read the audit

Every bullet/numbered requirement from the master is listed with its original section
context. “Implemented in stated research scope” means the concrete module/phase evidence
implements that feature subject to the explicit per-phase qualifier; it does not mean
unrestricted trading/regulatory accuracy. Optional choices are marked separately. Current
[limitations](../LIMITATIONS.md), [service contracts](../methodology/SERVICE.md),
[model cards](../models/INDEX.md) and [phase report](phase-12.md) define precise domains.

The suggested target tree is expressly adjustable: the actual typed src package uses
focused modules rather than empty folders. Collateral is inside domain/portfolio, capital
inside domain/ccr, processes inside domain/models, and command/job/service modules inside
application. API/CLI compose resources; infrastructure implements ports; domain/common
remain inward-only. No empty future model pages/directories are created for appearance.
ADRs 0001 and 0033–0036 document the actual service boundaries and decisions.

No fake financial engines, benchmark numbers, market observations, test outcomes or
compliance claims count as satisfaction. Synthetic data are labelled. Earlier phase
library calls remain available; successful service jobs additionally retain complete
request/result bytes and actual lineage. Source commit remains null when unavailable.
